# Presentation Narasi Auditchain

Folder ini adalah draft presentasi narasi baru yang berdiri sendiri dari `presentation-demo`.

## Run

```bash
npm install
npm run dev
```

Slidev akan berjalan di:

```text
http://localhost:3031
```

## Export

```bash
npm run export -- --output ../Progress_Agustus/Narasi_Auditchain_Gateway-Draft.pdf
```
